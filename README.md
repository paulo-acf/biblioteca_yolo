# **README**



### Este projeto consiste no estudo de uma biblioteca utilizada na linguagem Python. Cada aluno pôde escolher livremente uma biblioteca para estudo. No caso deste projeto, foi escolhida a biblioteca YOLO.

### 

### O presente sistema permite fazer classificação de cinco plantas por meio de imagens (usou-se 100 imagens para cada planta). Trata-se de PANCs - Plantas Alimentícias Não Convencionais (plantas que podem ser encontradas tanto na mata quanto em ambientes urbanos).

### 

### Numa tentativa de tornar este projeto mais didático, foram acrescentados comentários junto ao código (a ideia é tentar facilitar o entendimento e uma futura revisão — "A revisão é a mãe da retenção.").



## **• Para clonar o repositório:**



#### ```bash

#### git clone https://github.com/paulo-acf/biblioteca_yolo

#### ```



## **• Para criar o ambiente virtual:**



#### ```bash

#### python -m venv venv

#### ```



## **• Para ativar o ambiente virtual:**



#### ```bash (Windows)

#### venv\Scripts\activate

#### ```bash (Linux ou macOS)

#### source venv/bin/activate

#### ```



## **• Para instalar as dependências:**



#### ```bash

#### ```



## **• Para executar o projeto:**
